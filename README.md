# С Днём учителя!

Этот проект — универсальное праздничное поздравление ко Дню учителя для учителей русского языка и литературы. Сайт оформлен в стиле старой книги и современного минимализма, адаптирован под GitHub Pages и не требует сборки.

## Что включено
- Вступительная анимация "Открытая книга"
- Движущиеся буквы на фоне
- Секция с цитатами и карточками
- Словарь благодарности
- Мини-игра с вопросами по литературе
- Орфографический сюрприз
- Стена пожеланий с сохранением в `localStorage`
- Финальный салют и кнопка "Сказать спасибо"
- Тёмная тема через `prefers-color-scheme`
- Поддержка `prefers-reduced-motion`
- Кнопка фоновой музыки, по умолчанию выключена

## Файлы
- `index.html`
- `style.css`
- `script.js`

## Как изменить цитаты
Откройте файл `index.html` и найдите блок секции `quotes`. Там находятся карточки с цитатами. Заменяйте текст в элементах `.quote-text` и подписи в `.quote-author`.

Пример:
```html
<article class="quote-card">
  <p class="quote-text">«Новый текст»</p>
  <p class="quote-author">Автор</p>
</article>
```

Если вы не уверены в авторстве, лучше писать собственный текст без указания автора, как в проекте.

## Как изменить слова словаря
В секции `dictionary` в `index.html` найдите кнопки `.word-card` и их `data-word`. В JavaScript в объекте `dictionary` замените текст и значения по ключам: `терпение`, `мудрость`, `вдохновение`, `строгость`, `доброта`.

Пример:
```javascript
const dictionary = {
  терпение: {
    title: "Терпение",
    text: "Ваш текст..."
  }
};
```

## Как изменить вопросы викторины
В `script.js` найдите массив `questions` в функции `initQuiz()`. Меняйте массив объектов, где:
- `question` — текст вопроса
- `options` — варианты ответа
- `correct` — индекс правильного ответа

Пример:
```javascript
{
  question: "Кто автор ... ?",
  options: ["Вариант 1", "Вариант 2", "Вариант 3"],
  correct: 1
}
```

## Как изменить скорость анимаций
В `style.css` меняйте значения в секции с анимациями:

- `transition` у `.reveal`
- `animation` у `.floating-letter`
- `transition` у `.book-body`
- `animation` у `.book-cover`
- `@keyframes` для плавных эффектов

Для более медленной анимации увеличивайте значения в `s` или `ms`, для более быстрой — уменьшайте.

## Публикация на GitHub Pages
1. Загрузите проект в репозиторий GitHub.
2. Откройте репозиторий.
3. Перейдите в `Settings` → `Pages`.
4. В секции `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Сохраните.
6. GitHub Pages должен показать ссылку на ваш сайт, например:
   `https://username.github.io/repository-name/`

## Браузерная проверка
Проверьте сайт локально в браузере:
```bash
python -m http.server 8000
```
Откройте:
```text
http://localhost:8000
```
